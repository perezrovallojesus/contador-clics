# Reglas del proyecto

El usuario está aprendiendo desarrollo web desde cero y viene de diseño UI/UX.

1. HTML, CSS y JavaScript puros, sin frameworks, todo en `index.html`.
2. Pasos pequeños. Antes de cada cambio, explicar en 1-2 líneas qué hace y por qué.
3. Respuestas cortas, en español. Comentarios del código en español.
4. Commits pequeños, con mensajes claros en inglés.
